# foo_theme — foobar2000 WebView 主题

项目主页：[luna-kaze/foo_theme](https://github.com/luna-kaze/foo_theme) · 许可证：[GPLv3](LICENSE)（`GPL-3.0-only`）

基于 Vue 3、TypeScript、Vite 与 `foo-webview-sdk` 构建的现代 WebView2 深色中文播放器界面，通过 `foo_ui_webview2` 以宿主桥接方式运行于 foobar2000。

## 使用方法

### 环境要求

- foobar2000（推荐 2.x）
- 已安装并启用插件 `foo_ui_webview2`（主题核心宿主）
- 已安装 `foo_playcount`（播放统计与评分功能依赖）

### 构建

```bash
npm install
npm run build
```

生产产物输出到 `dist/`。将 `dist/` 目录的**内容**复制到：

```text
<foobar2000 profile>\webview-ui\default\
```

复制完成后，目标目录根下必须存在 `index.html`。重启 foobar2000 或重载当前 `foo_ui_webview2` 模板即可生效。

### 开发调试

```bash
npm run dev
```

将 `foo_ui_webview2` 的开发服务器地址指向 Vite 的 URL（通常为 `http://localhost:5173`）。在普通浏览器中打开同一地址会进入预览模式，使用本地模拟数据而非宿主桥接。
### 直接安装

从 GitHub Releases 下载 `dist.7z` 并解压，将其中的文件复制到：

```text
<foobar2000 profile>\webview-ui\default\
```

目标目录根下应存在 `index.html`。重启 foobar2000 或重载当前 `foo_ui_webview2` 模板即可。

## 包含的功能

### 媒体库浏览

- 概览：媒体库统计（曲目/专辑/艺术家数量、总时长、文件大小）、专辑速览、最近添加
- 艺术家：卡片与曲目列表；“获取资料 ▾”一键更新照片、简介与平台统计，照片和简介可独立搜索、预览、确认匹配，支持本地照片
- 专辑：专辑网格、专辑详情
- 歌曲：全库歌曲表，支持流派、播放统计筛选，高级字段/操作符筛选，Title Formatting 自定义列
- 文件夹：按 foobar2000 已配置的媒体库根目录逐级浏览
- 收藏、随机电台、全库搜索

### 播放与沉浸界面

- 完整播放控制：播放/暂停、上一首/下一首、seek、音量、静音、播放顺序
- 双缓冲播放工作集：保护当前解码、保留用户列表和待播编辑；三种本地播放策略及随机重排／恢复原序
- Standard 沉浸模式与 Coverflow 封面浏览（单击切换、双击播放）
- 歌词显示（内嵌/同名歌词文件）、同步歌词点击跳转、自动居中滚动
- 独立队列浮层；主窗口可缩为迷你播放器，点击 × 恢复原窗口
- 底部左侧卡片进入窗口沉浸，右侧按钮进入全屏沉浸；F11 仅在沉浸模式切换全屏
- 全屏 GPU 旋转封面背景、快速切歌快照交接及非 GPU 回退；全屏／窗口背景独立平滑交接
- 输出设备枚举与切换、桌面歌词入口
- AirPlay 实时信息与封面补读、原生远控切歌；接收记录统一末尾追加，未取得封面的中间记录不归档成黑卡，进度只读
- 插件扩展入口：转换（foo_converter）、获取专辑信息（foo_freedb）、完整 iPod 工作台与上下文操作（foo_dop）

### 媒体管理

- 曲目属性：标签查看、技术信息、播放次数、首次/最后播放、添加时间
- 元数据编辑：单曲及批量（标题/艺人/专辑/流派/日期/音轨号/碟片号）
- 0–5 星评分与批量评分；收藏使用隐藏歌单
- ReplayGain：查看 Track/Album Gain 与 Peak、按音轨/专辑扫描、清除
- 封面：查看、嵌入正面、移除嵌入封面
- 文件操作：重命名、移动（带确认）、回收站删除（带确认）、资源管理器定位

### 播放列表与队列

- 播放列表：创建、复制、清空、删除、排序、拖拽重排、撤销、原生移除重复项／无效项；主题隐藏 `AirPlay` 和 `TouchRemote Selection` 系统列表
- 自动播放列表（Auto Playlist）：按查询语句 + 排序规则创建与删除
- 队列：查看、添加、置顶、移除、清空
- 文件／文件夹拖到列表间隙新建歌单、拖到列表追加、拖到歌曲之间插入，或拖到左下卡片临时播放；每次拖放只执行一次
- 主题设置可配置导入排除后缀，默认过滤歌词、图片和文本等侧文件；保留 CUE/M3U/PLS 描述文件

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| F1 | 打开／关闭关于信息，显示项目链接和许可证全文 |
| F11 | 沉浸模式切换全屏；普通界面和迷你播放器阻断全屏 |
| Ctrl+Alt+B | 全屏背景实时调节、保存和恢复默认 |
| Ctrl+Alt+P | 开始／结束 Coverflow 性能采样并查看报告 |
| Ctrl+K | 聚焦全局搜索 |
| Esc | 关闭当前弹窗或退出沉浸模式 |

## 照片与标签操作

- 手动图片通过浏览器文件选择器读取用户选中的 `File`，不依赖系统盘任意路径的 `file.read` 权限；原生菜单启动时可能先显示“选择图片…”入口。
- 标签通过真实文件／容器路径读写，子音轨索引单独传递；异步写入完成后刷新，读取不完整时禁止保存空标签。
- 宿主的路径安全策略保持生效，主题不会修改全局路径白名单。

## 插件依赖

### 必要组件

| 插件 | 用途 |
| --- | --- |
| `foo_ui_webview2` | 主题核心宿主，提供界面渲染与 SDK 桥接（播放、媒体库、播放列表、队列、元数据、封面、歌词、窗口控制） |
| `foo_playcount` | 播放次数、首次/最后播放、添加时间、评分存储，支撑播放统计筛选 |

### 可选组件

| 插件 | 用途 |
| --- | --- |
| `foo_airplay` | `airplay://live/<generation>` 实时接收及原生 DACP 上一首／下一首转发 |
| `foo_converter` | 在曲目/专辑右键菜单中提供转换预设入口 |
| `foo_freedb` | 在专辑右键菜单中获取专辑信息（freedb） |
| `foo_dop` | 检测到组件后显示 iPod 工作台，提供上下文操作、同步、内容管理、设备属性、日志、数据库维护和安全弹出入口 |
| `foo_uie_eslyric` | 提供右上角固定的 ESLyric 桌面歌词入口 |

## 其他说明

- WebView SDK 无法增删 foobar2000 的媒体库监视文件夹，请通过「偏好设置」管理，再使用应用菜单中的「重新扫描媒体库」。
- `foo_dop` 未公开容量、电池、同步进度等设备数据接口；主题仅包装宿主动态发现的可执行命令，原生窗口负责实际设备操作。
- 打开本地文件或临时播放集合不会伪装成已加入媒体库。
